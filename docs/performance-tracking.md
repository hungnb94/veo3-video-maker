## Hướng dẫn thu thập metrics

### YouTube Studio
1. Mở YouTube Studio → Content → Shorts
2. Click vào video → Analytics
3. **Views (24h)**: Overview tab, filter "First 24 hours"
4. **Retention @30s**: Engagement → Audience retention chart, xem % tại 0:30
5. **CTR**: Reach → Impressions click-through rate

### TikTok Analytics
1. Mở TikTok → Profile → Creator tools → Analytics
2. Click vào video cụ thể
3. **Views**: Video views
4. **Watch Time**: Average watch time
5. **Retention**: Traffic source types → For You page %

### Instagram Insights
1. Mở Instagram → Reels → Click vào reel
2. View Insights
3. Ghi lại: Plays, Likes, Comments, Shares
